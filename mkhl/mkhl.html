Welcome here! Aren't you searching nice HLDM mod/client? You're found it!
Such a nice customization possibilities and QoL improvements in one mod [base],

Features

New HUD

Tired of default vanilla HUD? Reimplemented!
New HUD uses RmlUI in it's heart, this means new way of customization! RmlUI uses
HTML-like markup language to draw elements. So this is most user-friendly hud as possible :)

REGameUI [BETA]

Also, didn't you tired of this boring main menu?
For you, i, with huge help from ScriptedSnark reimplemented
GameUI.dll/.so and made it open-source!

Source viewmodel sway

Nothing special but sooo smooth. Definetly,
a catchy small thing that everyone needs.

KillFeed*

New hud i mentioned before allows us to
add new modificators to the killfeed, like in-air kill and headshots!

FreezePanel*

I think, anyone, when dies, was wondering about enemy HP.
So there it are, classic cs: source freeze panel!
